## ms ↔ timespec math

```
ms -> timespec:   tv_sec = ms / 1000        (Euclidean, ms >= 0)
                  tv_nsec = (ms % 1000) * 1000000
timespec -> ms:   ms = tv_sec * 1000 + tv_nsec / 1000000
```
nsec bound: tv_nsec in [0, 999999999] — the conversion above cannot
overflow it for ms >= 0. I64 ms overflows at ~292 million years of
uptime; carried as an honest non-limit.
