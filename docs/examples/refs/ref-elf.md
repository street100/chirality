## Minimal-file layout math (source: derived)

- file = ehdr(64) + phdr(56) + code; code file offset = 120 (0x78)
- load base p_vaddr = 0x400000 (conventional); p_offset = 0; whole file mapped
- e_entry = p_vaddr + code_offset = 0x400078
- p_filesz = p_memsz = 120 + len(code); p_align = 0x1000
- entry register state (System V psABI, x86-64): rsp -> [argc, argv...,
  NULL, envp..., NULL, auxv]; rdx = atexit fn or 0. argv/envp are STACK
  DATA at entry, not a syscall (the E32 env-get tie). Exit via syscall 60.
