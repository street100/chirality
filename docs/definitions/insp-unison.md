# Unison

A modern touchstone for one narrow but load-bearing point: code is not text.
Unison stores definitions content-addressed by the hash of their typed syntax
tree, so the codebase is a structured, queryable object rather than a pile of text
files, names are just metadata, and a definition once written never changes out
from under a caller.

**Lights up:** the substrate point in [[live-environment]]. The residential
lineage reflexively makes text the universal substrate; Unison is the proof that a
live system can treat code and data as typed structured values instead.

**chirality takes:** sessions and code as typed structured values reached through a
uniform port vocabulary, not text blobs ([[axis-typeability]]), and the stability
that comes from identity-by-structure rather than identity-by-name.

**chirality differs:** Unison is a single-language functional system, not a capability
process mesh. It fixes the substrate axis and leaves the isolation and authority
axes to the other inspirations. chirality takes only the "not text" lesson from it.
