<p>Computes the absolute value of an integer number.  The behavior is undefined if the result cannot be represented by the return type.
</p>

<h3><span class="mw-headline" id="Return_value">Return value</span></h3>
<p>The absolute value of <span class="t-c"><code class="mw-highlight mw-highlight-lang-c mw-content-ltr" dir="ltr"><span class="n">n</span></code></span> (i.e. <code>|n|</code>), if it is representable.
</p>
<h3><span class="mw-headline" id="Notes">Notes</span></h3>
<p>In 2's complement systems, the absolute value of the most-negative value is out of range, e.g. for 32-bit 2's complement type <code style="white-space: pre;" class="mw-highlight mw-highlight-lang-c mw-content-ltr" dir="ltr"><span class="kt">int</span></code>, <span class="t-lc"><a href="/c/types/limits" title="c/types/limits">INT_MIN</a></span> is <span class="t-c"><code class="mw-highlight mw-highlight-lang-c mw-content-ltr" dir="ltr"><span class="mi">-2147483648</span></code></span>, but the would-be result <span class="t-c"><code class="mw-highlight mw-highlight-lang-c mw-content-ltr" dir="ltr"><span class="mi">2147483648</span></code></span> is greater than <span class="t-lc"><a href="/c/types/limits" title="c/types/limits">INT_MAX</a></span>, which is <span class="t-c"><code class="mw-highlight mw-highlight-lang-c mw-content-ltr" dir="ltr"><span class="mi">2147483647</span></code></span>.
</p>
<h3><span class="mw-headline" id="Example">Example</span></h3>
<div class="t-example"><div class="t-example-live-link"><div class="coliru-btn coliru-btn-run-init">Run this code</div></div>
<div class="mw-highlight mw-highlight-lang-c mw-content-ltr" dir="ltr"><pre><span></span><span class="cp">#include</span><span class="w"> </span><span class="cpf">&lt;limits.h&gt;</span>
<span class="cp">#include</span><span class="w"> </span><span class="cpf">&lt;stdio.h&gt;</span>
<span class="cp">#include</span><span class="w"> </span><span class="cpf">&lt;stdlib.h&gt;</span>

<span class="kt">int</span><span class="w"> </span><span class="nf">main</span><span class="p">(</span><span class="kt">void</span><span class="p">)</span>
<span class="p">{</span>
<span class="w">    </span><span class="n">printf</span><span class="p">(</span><span class="s">&quot;abs(+3) = %d</span><span class="se">\n</span><span class="s">&quot;</span><span class="p">,</span><span class="w"> </span><span class="n">abs</span><span class="p">(</span><span class="o">+</span><span class="mi">3</span><span class="p">));</span>
<span class="w">    </span><span class="n">printf</span><span class="p">(</span><span class="s">&quot;abs(-3) = %d</span><span class="se">\n</span><span class="s">&quot;</span><span class="p">,</span><span class="w"> </span><span class="n">abs</span><span class="p">(</span><span class="mi">-3</span><span class="p">));</span>

<span class="c1">//  printf(&quot;%+d\n&quot;, abs(INT_MIN)); // undefined behavior on 2&#39;s complement systems</span>
<span class="p">}</span>
</pre></div>
<p>Output:
</p>
<div class="mw-highlight mw-highlight-lang-text mw-content-ltr" dir="ltr"><pre><span></span>abs(+3) = 3
abs(-3) = 3
</pre></div>
