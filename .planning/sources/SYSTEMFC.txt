No compiler usespureSystem F as an intermediate language,
because some source-language constructs can only be desugared
into pure System F by very heavy encodings. A good example is
the algebraic data types of Haskell or ML, which are made more

invariably extend System F by adding algebraic data types, data
constructors, andcaseexpressions. We will useFto describe

a typed intermediate language for source languages that embody
non-syntactic type equality -- and Haskell has developed several
such extensions. We have sketchily introduced SystemFas a
