      <h1 id="pagetitle"><span class="sc">Ascon</span></h1>
      <h2 id="pagesubtitle">Specification</h2>
    </div>


    <!-- content main -->
    <div id="content-main">

      <p>
      The <span class="sc">Ascon</span> family is specified in <a href="https://doi.org/10.6028/NIST.SP.800-232">NIST SP 800-232</a>: "Ascon-based Lightweight Cryptography Standards for Constrained Devices: Authenticated Encryption, Hash, and Extendable Output Functions".
      </p>

      <p>
      The original authenticated encryption (AEAD) and hashing schemes (Hash, XOF) <span class="sc">Ascon</span> as submitted to the LWC project are specified in the <a href="https://doi.org/10.1007/s00145-021-09398-9">Journal of Cryptology article</a>, the <a href="files/asconv12-nist.pdf">NIST submission</a>, and the <a href="files/asconv12.pdf">CAESAR submission</a>.
      Additionally, pseudorandom functions (PRF) and message authentication codes (MAC) are specified in the <a href="https://doi.org/10.1007/978-3-031-58868-6_15">CT-RSA 2024 paper</a>.
      </p>

      <p>
      NIST's draft standard is similar, but not identical to the submission. 
      Changes include the selection of a subset of schemes (with new names and IV constants); changing the mode to little-endian bit order; adding a customizable hash variant; and other flexible implementation options.
      Below, we provide a brief overview of the standardized schemes.
      For full details including the round constant and IV values, the little-endian bit ordering, padding rules, or the almost identical decryption mode, we refer to <a href="https://doi.org/10.6028/NIST.SP.800-232">NIST SP 800-232</a>.
      </p>

      <h3><span class="sc">Ascon</span>'s Permutation</h3>
      <p>
      All <span class="sc">Ascon</span> family members use the same lightweight permutation.
      This permutation iteratively applies an SPN-based round transformation for up to 16 rounds;
      the standardized modes of operation use 
      12 rounds in <span class="sc">Ascon</span>-<i>p</i>[12],
      and
      8 rounds  in <span class="sc">Ascon</span>-<i>p</i>[8].

      The round transformation consists of the following three steps which operate on a 320-bit state divided into 5 words <i>S</i><sub>0</sub>, <i>S</i><sub>1</sub>,  <i>S</i><sub>2</sub>, <i>S</i><sub>3</sub>, <i>S</i><sub>4</sub> of 64 bits each:
      </p>

      <ul>
        <li><span class="mark">Addition of Round Constants</span>: <span class="sc">xor</span>s a round-specific 1-byte constant to word <i>S</i><sub>2</sub>.</li>
        <li><span class="mark">Nonlinear Substitution Layer</span>: applies a 5-bit S-box 64 times in parallel in a bit-sliced fashion (vertically, across words).</li>
        <li><span class="mark">Linear Diffusion Layer</span>: <span class="sc">xor</span>s different rotated copies of each word (horizontally, within each word).</li>
      </ul>

      <h3>Authenticated Encryption with <span class="sc">Ascon-AEAD128</span></h3>
      <p>
      <span class="sc">Ascon</span> uses a <a href="http://sponge.noekeon.org/" target="_blank">duplex-based</a> mode of operation for authenticated encryption. The key, tag and nonce length is 128 bits.
      The sponge operates on a state of 320 bits, with message blocks of 128 bits.
      <!--</p>
      <p>-->
      The encryption process is split into four phases:
      </p>
      <ol>
        <li><span class="mark">Initialization</span>: initializes the state with the key <i>K</i>&nbsp; and nonce <i>N</i>.</li>
        <li><span class="mark">Associated Data Processing</span>: updates the state with associated data blocks <i>A<sub>i</sub></i>&nbsp;.</li>
        <li><span class="mark">Plaintext Processing</span>: injects plaintext blocks <i>P<sub>i</sub></i>&nbsp; into the state and extracts ciphertext blocks <i>C<sub>i</sub></i>&nbsp;.</li>
        <li><span class="mark">Finalization</span>: injects the key <i>K</i>&nbsp; again and extracts the tag <i>T</i>&nbsp; for authentication.</li>
      </ol>

      permutation <span class="sc">Ascon</span>-<i>p</i>[8] is applied to the complete state.
      During initialization and finalization, a stronger permutation <span class="sc">Ascon</span>-<i>p</i>[12] with more rounds is used.

      <h3>Hashing with <span class="sc">Ascon-Hash256</span> and <span class="sc">Ascon-(C)XOF128</span></h3>
      <p>
      The <span class="sc">Ascon</span> family includes
      the hash functions <span class="sc">Ascon-Hash</span> and the extendable output functions <span class="sc">Ascon-XOF128</span> with its customizable variant <span class="sc">Ascon-CXOF128</span>.
      The hashing modes use the same lightweight 320-bit permutation as the authenticated encryption modes.
      All variants use similar <a href="http://sponge.noekeon.org/" target="_blank">sponge-based</a> modes of operation and provide 128-bit security when using a hash size of at least 256 bits.
      </p>
      <div style='text-align:center'>
        <figure>
          <a class="figlink" href="images/hash.pdf"><img class="figlink" alt="Ascon's sponge mode for hashing: Ascon-Hash256 and Ascon-XOF128"   src="images/hash_small.png"/></a>
          <a class="figlink" href="images/cxof.pdf"><img class="figlink" alt="Ascon's sponge mode for customizable hashing: Ascon-CXOF128"   src="images/cxof_small.png"/></a>
          <figcaption>
            Hashing mode for <span class="sc">Ascon-Hash256</span>, <span class="sc">Ascon-XOF128</span> (top) and <span class="sc">Ascon-CXOF128</span> (bottom) &nbsp; &nbsp;
            [<a href="images/asconfigures.zip">tex</a>]
          </figcaption>
        </figure>
      </div>

      <p>
      The hashing modes absorb the message <i>M</i>&nbsp; in 64-bit blocks <i>M<sub>i</sub></i>&nbsp;
      and finally squeeze the hash value <i>H</i>&nbsp; in 64-bit blocks <i>H<sub>i</sub></i>&nbsp;.

      The customizable variant additionally absorbs a customization string <i>Z</i>&nbsp; in 64-bit blocks <i>Z<sub>i</sub></i>&nbsp; before the message <i>M</i>.

      After each absorbed or squeezed block, the
      permutation <span class="sc">Ascon</span>-<i>p</i>[12] is applied to the state.
      </p>
