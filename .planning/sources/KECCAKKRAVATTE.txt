<h1 class="page-title"><span class='sc'>Kravatte</span></h1>
</div>
</header>
<div class="container">
<div class="panel panel-default">
<div class="panel-body">

<p><span class='sc'>Kravatte</span> is a <a href="glossary.html#deck_function">deck function</a>, on top of which we define simple modes:</p>
<ul>
    <li><span class='sc'>Kravatte</span>-SANE, an authenticated encryption scheme supporting sessions, like <span class='sc'>Ketje</span> and <span class='sc'>Keyak</span>;</li>
    <li><span class='sc'>Kravatte</span>-SANSE, an authenticated encryption scheme supporting sessions and using the synthetic initial value (SIV) technique, robust under nonce repetitions;</li>
    <li><span class='sc'>Kravatte</span>-WBC, a wide-block cipher for authenticated encryption with minimal expansion.</li>
</ul>

<p><span class='sc'>Kravatte</span> builds upon the <span class='sc'>Keccak</span>-<i>p</i> permutations and the novel Farfalle construction, which can somehow be seen as the parallel counterpart of the sponge construction. It thus provides inherent parallelism that can be readily exploited on platforms supporting SIMD instruction sets or multiple cores.</p>

</div>
</div>
